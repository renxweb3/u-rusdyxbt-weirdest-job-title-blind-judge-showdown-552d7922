One job title, the weirdest one we could think of: Senior Apologizer for
Self-Driving Shopping Carts. It sounds like a real senior role until the
last three words, and then it very much does not.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
